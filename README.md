# Carnet

Installateurs de Carnet, bullet journal de bureau (Linux, Windows, macOS). Le code source est privé.

Télécharger : onglet Releases, dernière version. Vérifier un fichier : `sha256sum -c SHA256SUMS --ignore-missing`.

- Linux : rendre le fichier .AppImage exécutable puis le lancer.
- Windows : lancer le .exe (Windows peut avertir : application non signée, « Informations complémentaires » puis « Exécuter quand même »).
- macOS : dézipper, glisser Carnet dans Applications, puis clic droit et « Ouvrir » la première fois (application non signée).
